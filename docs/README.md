## 一、项目简介

「技匠」是一个面向高校垂直场景的 C2C 技能交易与知识共享平台。通过 **实名认证 + 担保交易** 模式，为在校大学生提供合规、安全、高性价比的本校朋辈学业帮扶与技能辅导服务。

- **客户端形态**：微信小程序（主端），保留多端扩展能力
- **架构模式**：前后端分离 + 单体后端（SpringBoot）+ 云托管数据库
- **核心业务**：实名认证、服务发布、担保交易、双向评价、争议仲裁
- **商业模式**：交易佣金（6% ~ 10%）+ 增值服务 + 校园合作

更多业务背景详见 [产品立项书](./产品立项书.md)。

## 五、核心里程碑（摘要）

详细排期与验收标准见 [10-迭代计划与里程碑](./10-迭代计划与里程碑.md)。

| 阶段 | 周期 | 关键里程碑 |

## 六、如何使用本文档

1. **新人上手**：按"文档索引"中建议的顺序通读，重点关注 01、06、10。
2. **编码前**：阅读对应模块的 03/04 章节与 09 开发规范，再动手。
3. **联调前**：以 05 API 接口规范作为唯一契约。
4. **上线前**：对照 07 与 08 做安全与部署自查。
5. **文档更新**：任何架构/接口/数据库变更，必须同步更新本目录下相关文档，并在 Git 提交信息中标注 `docs:` 前缀。
