### 1.2 包划分原则

1. **按业务模块聚合**（modules/user、modules/order）而非按层横切。单模块内可继续分层。
2. **common** 存放全局通用，不依赖任何业务模块。
3. **infra** 存放基础设施封装，为业务层提供统一入口（如 `RedisHelper`、`PaymentServerClient`）。
4. **job** 存放所有定时任务/延迟任务，避免散落在业务模块。

## 2. 基础约定

### 2.1 统一响应格式

所有接口返回 `Result<T>`：

```java
public class Result<T> {
    private int    code;      // 0 成功；非 0 失败
    private String message;   // "success" 或错误描述
    private T      data;      // 业务数据
    private long   timestamp;

    public static <T> Result<T> ok(T data) { ... }
    public static <T> Result<T> ok()       { return ok(null); }
    public static <T> Result<T> fail(int code, String msg) { ... }
}
```

- 业务错误码统一在 `ErrorCode` 枚举维护；按模块分段（10001~19999 为 user，20001~29999 为 order……）
- HTTP Status Code：**仅用 200 / 401 / 403 / 404 / 500**；业务错误一律 200 + `code != 0`

### 2.2 全局异常处理

```java
@RestControllerAdvice
public class GlobalExceptionHandler {

    @ExceptionHandler(BusinessException.class)
    public Result<?> handleBiz(BusinessException e) {
        log.warn("业务异常: {}", e.getMessage());
        return Result.fail(e.getCode(), e.getMessage());
    }

    @ExceptionHandler(MethodArgumentNotValidException.class)
    public Result<?> handleValid(MethodArgumentNotValidException e) {
        String msg = e.getBindingResult().getFieldError().getDefaultMessage();
        return Result.fail(ErrorCode.PARAM_INVALID.getCode(), msg);
    }

    @ExceptionHandler(Exception.class)
    public Result<?> handleUnknown(Exception e) {
        log.error("系统异常", e);
        return Result.fail(ErrorCode.SYSTEM_ERROR.getCode(), "系统繁忙，请稍后重试");
    }
}
```

#### 3.1.4 RBAC 权限（自定义注解 + 拦截器）

```java
@Target(ElementType.METHOD)
@Retention(RetentionPolicy.RUNTIME)
public @interface PreAuth {
    String role() default "";
    boolean requireVerify() default false;
    boolean requireDeposit() default false;
}

@Component
@RequiredArgsConstructor
public class AuthInterceptor implements HandlerInterceptor {

    private final UserMapper userMapper;
    private final JwtHelper   jwtHelper;

    @Override
    public boolean preHandle(HttpServletRequest req, HttpServletResponse resp, Object handler) {
        if (!(handler instanceof HandlerMethod hm)) return true;
        PreAuth anno = hm.getMethodAnnotation(PreAuth.class);
        if (anno == null) return true;

        String token = resolveToken(req);
        if (StringUtils.isBlank(token)) throw new BusinessException(ErrorCode.UNAUTHORIZED);

        Claims claims = jwtHelper.parse(token);
        Long userId = claims.get("uid", Long.class);
        User user = userMapper.selectById(userId);
        if (user == null || user.getStatus() != 1) throw new BusinessException(ErrorCode.USER_INVALID);

        if (!anno.role().isEmpty()) {
            if (!hasRole(user, anno.role())) throw new BusinessException(ErrorCode.NO_PERMISSION);
        }
        if (anno.requireVerify() && user.getVerifyStatus() != VerifyStatus.APPROVED.getCode()) {
            throw new BusinessException(ErrorCode.NOT_VERIFIED);
        }
        if (anno.requireDeposit() && user.getDepositPaid() != 1) {
            throw new BusinessException(ErrorCode.DEPOSIT_REQUIRED);
        }

        UserContextHolder.set(new UserContext(userId, user.getCampusId(), user.getCurrentRole()));
        return true;
    }

    @Override
    public void afterCompletion(...) { UserContextHolder.clear(); }
}
```

#### 3.2.2 检索：MySQL FULLTEXT + Redis

```java
public Page<ServiceItemVO> search(SearchDTO dto, Long campusId) {
    String cacheKey = String.format("search:%d:%s:%d:%d",
            campusId, DigestUtils.md5Hex(JSON.toJSONString(dto)), dto.getPage(), dto.getSize());

    String cached = redisHelper.get(cacheKey);
    if (cached != null) return JSON.parseObject(cached, new TypeReference<>() {});

    Page<ServiceItem> page = mapper.searchByKeyword(
            new Page<>(dto.getPage(), dto.getSize()),
            campusId, dto.getCategoryId(), dto.getKeyword(),
            dto.getMinPrice(), dto.getMaxPrice());

    List<ServiceItemVO> vos = page.getRecords().stream()
            .map(this::enrichWithSellerCredit)
            .sorted(this::scoreComparator)
            .toList();

    Page<ServiceItemVO> result = new Page<>(page.getCurrent(), page.getSize(), page.getTotal());
    result.setRecords(vos);

    redisHelper.set(cacheKey, JSON.toJSONString(result), Duration.ofMinutes(10));
    return result;
}

private int scoreComparator(ServiceItemVO a, ServiceItemVO b) {
    double scoreA = a.getMatchScore() * 0.4 + a.getCreditScore() * 0.3
                  + a.getSales() * 0.2 + freshness(a.getPublishTime()) * 0.1;
    double scoreB = b.getMatchScore() * 0.4 + b.getCreditScore() * 0.3
                  + b.getSales() * 0.2 + freshness(b.getPublishTime()) * 0.1;
    return Double.compare(scoreB, scoreA);
}
```

```xml

           MATCH(title, description) AGAINST(#{keyword} IN NATURAL LANGUAGE MODE) AS match_score
```

```java
public OrderVO createOrder(CreateOrderDTO dto, UserContext ctx) {

    order.setSellerId(item.getSellerId());
    order.setServiceId(item.getId());
```

#### 3.3.3 状态机实现

```java
@Service
@Slf4j
public class OrderStateMachine {

    private static final Map<Integer, Set<Integer>> TRANSITION = Map.of(
        10, Set.of(20, 60),
        20, Set.of(30, 60),
        30, Set.of(40, 70),
        40, Set.of(50, 70),
        70, Set.of(80, 50)
    );

    public void assertCanTransit(int from, int to) {
        Set<Integer> next = TRANSITION.getOrDefault(from, Set.of());
        if (!next.contains(to)) {
            throw new BusinessException(ErrorCode.ORDER_STATUS_ILLEGAL,
                String.format("订单状态不可从 %d 流转到 %d", from, to));
        }
    }

    @Transactional
    public void transit(Long orderId, int to, int operatorType, Long operatorId, String remark) {
        OrderMain order = orderMapper.selectByIdForUpdate(orderId);
        assertCanTransit(order.getStatus(), to);
        orderMapper.updateStatus(orderId, order.getStatus(), to);
        orderLogMapper.insert(new OrderLog(orderId, order.getStatus(), to, operatorType, operatorId, remark));
    }
}
```

### 3.4 支付与资金模块（payment）

#### 3.4.1 A/B 支付服务拆分

V1.0 真实支付不再保留旧的模拟支付入口。A 设备运行主后端与前端，B 服务器运行独立 `jijiang-payment-server`，并持有虎皮椒 `appid/appsecret`。

```text
MiniApp -> A: POST /api/order/create
MiniApp -> A: POST /api/payment/create {orderId}
A -> B: POST /internal/payment/orders   (HMAC-SHA256)
B -> 虎皮椒: POST /payment/do.html
虎皮椒 -> B: POST /api/payment/xunhu-notify
B -> A: POST /internal/payment/callback (HMAC-SHA256)
A: payment_record 摘要成功 + order_main 10 -> 20
```

A 后端只负责：

- 校验买家身份、订单状态、订单金额。
- 通过 `PaymentServerClient` 调用 B 的 `/internal/payment/orders`。
- 写入或复用 A 侧 `payment_record` 摘要，供订单详情和运营后台展示。
- 只接受 B 的 `/internal/payment/callback`，不直接接收虎皮椒回调。

B 支付服务负责：

- 调用虎皮椒下单接口并保存真实支付流水。
- 接收虎皮椒 `notify_url`，完成虎皮椒验签、`appid` 校验、金额校验和幂等。
- 将成功结果回推 A；回推失败时记录 `app_callback_status=2` 并定时重试。

#### 3.4.2 A/B 内部签名

A→B 与 B→A 均使用共享密钥 HMAC-SHA256，固定请求头：

```text
X-JJ-Client-Id
X-JJ-Timestamp
X-JJ-Nonce
X-JJ-Signature
```

签名串：

```text
timestamp + "\n" + nonce + "\n" + method + "\n" + path + "\n" + sha256(body)
```

接收方必须校验：

- `clientId` 与配置一致。
- `timestamp` 与本机时间偏差不超过 5 分钟。
- `nonce` 使用 Redis `SETNX` 防重放；本地测试可降级为进程内缓存。
- 签名使用 `MessageDigest.isEqual` 做常量时间比较。

```java
                                                pay.getAmount(), amount, reason);
```

```java
private int computeCreditDelta(int score) {
    return switch (score) {
        case 5 -> 2;
        case 4 -> 1;

        case 2 -> -3;
```

#### 3.7.1 敏感词匹配（DFA）

```java
@Component
public class SensitiveWordFilter {

    private volatile TrieNode root;

    @PostConstruct
    public void init() { rebuild(); }

    public void rebuild() {
        List<String> words = sensitiveWordMapper.listAll();
        TrieNode newRoot = new TrieNode();
        words.forEach(w -> addWord(newRoot, w));
        this.root = newRoot;
    }

    public List<String> match(String text) {
        List<String> hits = new ArrayList<>();
        char[] chars = text.toCharArray();
        for (int i = 0; i < chars.length; i++) {
            TrieNode p = root;
            int j = i, start = i;
            StringBuilder sb = new StringBuilder();
            while (j < chars.length && p.children.containsKey(chars[j])) {
                p = p.children.get(chars[j]);
                sb.append(chars[j]);
                j++;
                if (p.isEnd) hits.add(sb.toString());
            }
        }
        return hits;
    }
}
```

### 4.2 延迟队列（Redis ZSet）

```java
@Component
@RequiredArgsConstructor
public class DelayQueue {

    private final StringRedisTemplate redis;

    public void push(String queue, Long bizId, Duration delay) {
        long score = System.currentTimeMillis() + delay.toMillis();
        redis.opsForZSet().add("delay:" + queue, String.valueOf(bizId), score);
    }

    public Set<String> pop(String queue, int limit) {
        long now = System.currentTimeMillis();
        Set<ZSetOperations.TypedTuple<String>> set = redis.opsForZSet()
                .rangeByScoreWithScores("delay:" + queue, 0, now, 0, limit);
        if (set == null || set.isEmpty()) return Set.of();

        Set<String> result = new LinkedHashSet<>();
        for (var t : set) {
            Long removed = redis.opsForZSet().remove("delay:" + queue, t.getValue());
            if (removed != null && removed == 1) result.add(t.getValue());
        }
        return result;
    }
}
```

## 7. 开发流程建议

1. **建表**：Flyway 脚本 → 本地执行 → 生成实体
2. **实体/Mapper**：使用 MyBatis-Plus 代码生成器
3. **DTO/VO**：手写；不自动生成以保持可读性
4. **Service**：先定义接口（便于 Mock 测试）
5. **Controller**：最后写，聚焦入参校验与响应组装
6. **单元测试**：核心 Service 必测；Mapper 用 H2 或 Testcontainers
7. **集成测试**：下单/支付/退款的关键路径
